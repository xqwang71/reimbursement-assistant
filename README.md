# 报销助手开源版

在自己的电脑上核对票据、匹配经费、填报上经贸大学的报销单，并把学校导出表汇总为项目执行看板。Mac 和 Windows 共用一套程序。首次打开可直接试用虚构报销汇总。

## 打开助手

1. 安装 [Node.js 22.13 或更新版本](https://nodejs.org/)和 [Python 3.11 或 3.12](https://www.python.org/downloads/)。Windows 安装 Python 时建议启用 Python Launcher 或加入 PATH。
2. 解压整份源码。Mac 双击 `打开报销助手.command`，Windows 双击 `打开报销助手.cmd`。也可在该文件夹的终端运行 `npm run launch`。首次启动需联网安装 Node.js 依赖和 Excel、PDF 读取组件。
3. 如果浏览器未自动打开，在本机访问 [127.0.0.1:3033](http://127.0.0.1:3033/)。关闭启动窗口会结束服务。

正式填报时，Mac 使用 Chrome，Windows 可使用 Chrome 或 Edge。需指定浏览器时，可在启动前设置 `REIMBURSEMENT_BROWSER_BIN` 为浏览器可执行文件的完整路径。

## 试用示例

首次打开会直接显示 2099 年的虚构数据。项目甲的预算为 ¥12,000，学校已报销 ¥1,350，已提交待入账 ¥450，执行率为 **15%**。展开项目可追溯到 Excel 的表名和行号。示例模式可查看、下载和导出示例数据，学校登录、同步和填报接口关闭。

| 文件 | 用途 |
| --- | --- |
| `2099年度进账与报销台账.xlsx` | 项目经费汇总模板，含「年度汇总」「项目清单」「学校项目匹配」「代人报销分配」 |
| `报销单统计.xlsx` | 智能报销导出格式 |
| `报销单查询.xls` | 日常线下预约报销导出格式 |
| `学生劳务费导出.xls`、`校外人员劳务费导出.xls` | 薪酬申报导出格式 |

在「数据来源与导出」可下载台账和样表，源码里的副本在 `examples/2099/`。制作自己的台账时，把模板另存到自己的年度票据目录，替换示例数据，并按年度命名为 `YYYY年度进账与报销台账.xlsx`。项目清单使用学校项目编号关联导出表。

## 使用自己的票据

1. 点「设置我的报销」，填入本机年度票据文件夹路径。Mac 可在 Finder 选中文件夹后用 Option + Command + C 复制路径，Windows 可用资源管理器的「复制文件地址」。也可使用预填的本机目录。
2. 将学校导出的 Excel 放在年度目录顶层，然后点「重新读取执行表」。按事项整理的发票、付款记录和附件放在子文件夹。需要从网页拉取导出时，点「同步学校执行表」。学校登录和校园网或 aTrust 连接由本人在同一台电脑完成。
3. 在工作清单合并同一事项的来源文件夹，填写用途、匹配经费并核对。教学和科研加签人默认留空，可在设置里添加常用姓名和工号，也可在单笔详情或薪酬申报中指定。贸大出行使用所选经费口径的常用加签人。可在「按项目指定科研经费」填写项目编号，之后保存这些项目的匹配时自动选择科研口径。
4. 点「填报选中项」。执行区逐笔显示金额、项目和审批或预约信息。核对后点「确认提交本笔」。选「先别提交」会保留原单供核对。若结果不确定，按学校原单核实再继续。

日常线下预约可在设置里选择校区和学校页面显示的支付类型。预约完成后自动保存 PDF。自动打印默认关闭，开启后使用系统默认打印机。Windows 的自动打印还需要默认 PDF 程序支持 Print 操作。

## 附件识别和外部模型

在项目目录运行以下命令，安装本机附件识别组件。

```sh
npm run launch -- --install-ocr
```

OCR 在本机运行。四个外部模型场景默认关闭。关闭时仍可读 Excel、做汇总及使用本机规则核对材料。需要提取新差旅行程时，可在设置中单独开启「差旅核对」。姓名不参与模型提取，关联学校出差申请时按页面提示核对单号。

可使用本机的 ChatGPT / Codex 登录，也可配置第三方模型，例如 DeepSeek API。两种方式都需要安装本机 Codex CLI。Windows 如需手动指定 Codex，将 `CODEX_BIN` 设为 `codex.exe` 的完整路径。

使用 DeepSeek 时，在系统中设置 `DEEPSEEK_API_KEY` 环境变量，重启助手，在「连接与凭据」选择预设的「DeepSeek API」连接，再在「使用场景」为需要开启的功能选择 DeepSeek 并保存。API Key 保存在系统环境变量里，助手设置中填写变量名。也可通过「添加连接」接入其他兼容 OpenAI Responses API 的服务，并在「模型配置」填写服务商提供的模型名称。DeepSeek 的接口和模型名称见 [DeepSeek 官方文档](https://api-docs.deepseek.com/guides/responses_api/)。

启用场景前，设置页会说明发送内容。发送前会以代号替换附件名，并尽量遮盖带标签的姓名、身份证、卡号、手机号和邮箱。手写消息和 OCR 文字仍可能含其他个人信息。

## 本机数据与公开文件

| 平台 | 默认用户数据目录 |
| --- | --- |
| macOS | `~/Library/Application Support/ReimbursementAssistant` |
| Windows | `%LOCALAPPDATA%\ReimbursementAssistant` |

程序只在本机回环地址监听。用户数据目录下的 `.runtime` 用 JSON 保存设置、待办、项目匹配、执行记录和学校回执，专用浏览器会话和识别缓存也保存在这里。经费汇总按所选票据目录的项目台账、学校 Excel 导出和本机执行回执计算。发票、附件和年度 Excel 由使用者保存在自己选定的票据目录。

公开文件提供虚构样表。首次启用正式模式时，每位使用者填写自己的设置。外部模型场景默认关闭。公开问题反馈可提供复现步骤、版本和虚构数据。共享日志或图片前请移除姓名、金额、账号、单号及路径。

更新前先关闭正在运行的助手。可在同一台电脑上替换源码目录，或解压新版后从新版启动，原本的本机用户数据会继续使用。想沿用自己选定的用户数据目录时，启动前把 `REIMBURSEMENT_RUNNER_DATA_DIR` 设为该目录的绝对路径。目录应在源码之外。使用两个用户数据目录时，分别设置 `PORT` 并使用对应的本机地址。

## 初次使用

1. **打开网页。** 下载并解压源码，按上面的「打开助手」启动。浏览器通常会自动打开，也可手动访问 [127.0.0.1:3033](http://127.0.0.1:3033/)。使用期间请保持启动窗口开启。
2. **先看样例。** 首页会显示 2099 年的虚构数据。展开项目甲，可以查看已报销、待入账和执行率各自来自哪张表。需要空白格式时，可从「数据来源与导出」下载样表，另存后替换示例数据。
3. **设置自己的报销目录。** 点「设置我的报销」，选择本机存放当年票据的文件夹。按报销事项建子文件夹，把发票、付款凭证和其他附件放到对应子文件夹。用于经费汇总的年度台账和学校导出表放在年度目录顶层。
4. **先核对一笔。** 在「批量工作清单」点「刷新文件夹」，选一笔事项，填写报销事由、匹配经费，再核对金额和附件。需要登录学校系统时，按页面提示在本机完成登录。
5. **核对后提交。** 勾选该事项，点「填报选中项」。在「执行与互动」里核对金额、项目及审批或预约信息，确认无误后点「确认提交本笔」。想先检查学校页面上的原单，可点「先别提交」。

## 验证

`npm run check` 检查源码语法。运行 `npm test` 前，安装 `requirements.txt` 中的依赖及测试用的 `PyMuPDF`。服务测试用虚构材料，浏览器测试使用本机模拟页面和独立会话。GitHub Actions 配置分别在 Mac 和 Windows 运行。校园登录、真实填报和实际打印需要在相应电脑上核验。

项目为独立工具。学校系统入口、授权和报销口径以校方当前规则为准。
